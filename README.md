## 📖 About The Project
D-Store is a fully responsive e-commerce frontend designed to provide a premium, seamless shopping experience. It features an intuitive user interface, a functional shopping cart, and a categorized product catalog (Kids, Beauty, Fashion, Design). The architecture is designed to integrate heavily with a Headless CMS (Sanity.io) for dynamic, real-time inventory and content management.

This project was built to showcase scalable frontend development practices, modern UI/UX implementation, and robust API integration — making it a prime example of production-ready React code.

## ✨ Key Features
* **Modern Architecture**: Built with React, Vite, TypeScript, and Tailwind CSS for lightning-fast performance.
* **Headless CMS Integration**: Seamlessly connects with Sanity.io for dynamic product and content management.
* **Responsive Layout**: Mobile-first design ensuring a flawless and cohesive experience across mobile, tablet, and desktop.
* **State Management**: Custom Context-based cart system with `localStorage` persistence.
* **Serverless Forms**: Fully functional Contact Support forms powered by Netlify Forms integration.
* **Clean UI/UX**: Professional, modern styling with subtle hover states, clean typography, and Lucide React icons.
